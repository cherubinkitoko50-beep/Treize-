# TREIZE+ — Prototype premium V1

Prototype web interactif rebrandé sous TREIZE+, basé sur la maquette premium précédente.

## Tester
Ouvrir `index.html` dans un navigateur moderne. Une connexion Internet est nécessaire pour les images distantes et les polices externes.

## Ce qui fonctionne dans cette maquette
- Interface responsive pour mobile et ordinateur
- Navigation mobile avec 5 entrées : Accueil, Explorer, TV en direct, Favoris et Profil
- Recherche et fiches de contenus de démonstration
- Ajout/retrait de favoris conservés dans le stockage local du navigateur
- Sections Favoris et Profil de démonstration
- Manifeste PWA de base pour préparer l'installation depuis un hébergement HTTPS compatible

## Limites actuelles — à ne pas confondre avec un service lancé
- Aucun flux TV/film réel n'est connecté
- Aucun système de comptes, base de données ou gestion d'abonnements
- Aucun paiement Mobile Money ou carte n'est branché
- Les chaînes, rencontres et programmes sont fictifs/de démonstration
- Les contenus réels ne doivent être ajoutés qu'après validation des droits de diffusion et de redistribution par territoire
- Le manifeste est une préparation PWA, pas une garantie d'installation ni une application publiée dans les stores

## Important
Les favoris restent locaux à cet appareil et ne sont pas synchronisés entre comptes. La section Profil est illustrative : aucune authentification réelle n’est connectée.

## Prochaine étape
Construire l'architecture réelle par étapes : choisir une source de contenus légalement autorisée, puis définir backend/catalogue, authentification, gestion des droits par pays, puis abonnements et paiements adaptés aux marchés ciblés.
